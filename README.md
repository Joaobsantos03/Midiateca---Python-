# Midiateca

Projeto desenvolvido em Python com o objetivo de praticar e aplicar os conceitos que venho aprendendo durante meus estudos.

A Midiateca é um sistema executado pelo terminal para gerenciamento de diferentes tipos de mídia, como livros, jogos e filmes.

## Funcionalidades

- Cadastro de livros, jogos e filmes
- Listagem de midia
- Empréstimo de itens
- Devolução de itens
- Controle de disponibilidade
- Salvamento e carregamento do acervo através de arquivo JSON

## Conceitos aplicados

Durante o desenvolvimento do projeto foram utilizados conceitos como:

- Programação Orientada a Objetos
- Classes e objetos
- Herança
- Encapsulamento
- Polimorfismo
- Listas e dicionários
- Manipulação de arquivos
- JSON
- Modularização do código
- Ambiente virtual (venv)
- Git e GitHub

## Estrutura do projeto

O projeto é dividido em módulos responsáveis pelos modelos das mídias, funcionalidades do sistema, persistência dos dados e execução do programa.

Os dados do acervo são armazenados em um arquivo JSON, permitindo que alterações como empréstimos e devoluções sejam mantidas mesmo após o encerramento do programa.
